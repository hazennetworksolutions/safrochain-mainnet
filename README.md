## 📋 Overview

Safrochain is a Cosmos SDK Layer-1 blockchain focused on mobile-first payments and remittances, built for Africa and open to the world. It is built on Cosmos SDK v0.50 and CometBFT v0.38.

Mainnet (`safrochain-1`) went live on **June 25, 2026** with genesis time `2026-06-25T10:00:00Z`. Additional validators join on-chain via `MsgCreateValidator` after syncing.

- Official Docs: [docs.safrochain.com](https://docs.safrochain.com)
- GitHub: [github.com/Safrochain-Org/safrochain-node](https://github.com/Safrochain-Org/safrochain-node)
- Explorer: [status.safrochain.network](https://status.safrochain.network)
- RPC: [rpc.safrochain.network](https://rpc.safrochain.network)
- REST: [api.safrochain.network](https://api.safrochain.network)
